> **关于负载阻值与物理上限（已实机验证）**：当前实板使用 **`INA219` (`R100 = 0.1Ω`)**，`±320mV` 档硬件量程高达 **`3.2A`**（固件在 `INA219` 下自动放宽软件 `OCP` 至 `2.0A / 2.5A`，插回 `INA226` 自动回落 `750mA`）。  
> 欧姆定律上限 $P_{\max} = \frac{V^2}{R} \times 0.95$：单颗 `10Ω` 在 `12V / 9V / 5V` 实测上限分别约为 **`12.4W / 7.0W / 2.2W`**；`35Ω` (`10+10+15`) 在 `12V / 9V` 上限约为 **`3.9W / 2.1W`**；若需用 `12V 20W` 充电头跑到 `18~20W`，可用 **`10Ω // 15Ω` 并联 (`6.0Ω`)** 或换 `20V` PD 充电头配 `10Ω~20Ω`。**切勿用 `0.1Ω~1Ω` 电阻直连或把 `GND` 接到 `INA219 Vin-`！**

## 2. 系统连接拓扑图

### 功率主回路（高电压 `5V ~ 20V`，严禁接入单片机任何 IO / VDD）

```text
[Type-C PD 充电头] ──(C-to-C)──▶ [炬为测试仪] ──(C-to-C)──▶ [HUSB238 Type-C 母座]
                                                                │ (黑色 2P 端子 左口 V+ / 右口 GND)
                                                                ▼
[INA219 绿色端子右口 Vin+] ◀── 接 HUSB238 黑色端子左口 V+（INA219 无需 VBS 飞线！）
[INA219 绿色端子左口 Vin-] ──▶ [双 MOS 背面丝印 VIN+]（正面右上蓝色螺丝口）
[HUSB238 黑色端子右口 GND] ─▶ [双 MOS 背面丝印 VIN-]（正面右下蓝色螺丝口，并与单片机 GND 共地）
[双 MOS VOUT+ / VOUT-]（正面左侧上下口）──▶ [黄金铝壳电阻：10Ω 或 35Ω]
```

### 控制与信号回路（全部 `3.3V` 逻辑电平）

| 信号功能 | PY32F003 开发板引脚 | 对接目标模块引脚 | 备注 |
|---|---|---|---|
| **I2C1 SCL** | `PB6` (AF6, 100kHz) | `HUSB238 SCL` + `INA219 Scl` | 两模块并联共用总线（借用 INA219 板载 10kΩ 上拉） |
| **I2C1 SDA** | `PB7` (AF6, 100kHz) | `HUSB238 SDA` + `INA219 Sda` | 同上（注意两块板 `SCL/SDA` 丝印左右顺序相反） |
| **逻辑供电 3.3V** | `VDD` (`3.3V`) | `INA219 Vcc` | **`HUSB238 V+` 不接单片机！HUSB238 由 Type-C 自取电，仅连 `SDA/SCL/GND`** |
| **过流报警输入** | `PA4` (上拉输入 + `EXTI4` 下降沿中断) | `INA226 ALE`（`INA219` 时悬空不接） | `INA226` 模式下触发 `EXTI4` 中断立即硬件关断 `TIM1_CH3`；`INA219` 模式下自动关闭 `EXTI4` 防悬空误触发，由 `20ms` 控制环执行软件 `OCP` |
| **20kHz PWM** | `PA0` (TIM1_CH3, AF13) | `双 MOS 模块 TRIG/PWM` | 推挽输出；复位/未配置期间 GPIO 为高阻态，**必须在 MOS 输入端并 `10kΩ` 外部下拉电阻**保证上电及复位默认关断 |
| **串口 TX→RX** | `PA2` (USART2_TX, AF4) | `CH340 RXD` | `115200 8N1` |
| **串口 RX←TX** | `PA3` (USART2_RX, AF4) | `CH340 TXD` | 接收 `V / P / A / C / L / E / T / O / W / H` 指令 |
| **系统共地** | `GND` | `HUSB238 黑色端子右口 GND` + `INA219 排针 Gnd` + `双 MOS GND` + `CH340 GND` | 全部必须共地（否则 I2C 失联且 `VBUS` 漂移为 `~868mV`） |
| **SWD 烧录** | 右侧 `P4` (`RST/CLK/GND/DIO/VDD`) | `ST-Link / J-Link / DAP` | 与板载 Type-C 供电二选一，避免两路 3.3V/5V 同时硬并 |
| **启动配置** | 右下 `P5` (`VCC / BOOT0 / GND`) | 跳线帽短接 `BOOT0` 与 `GND` | 上电从主 Flash 启动 |
| **TFT SPI 时钟** | `PA5` (`SPI1_SCK`, AF0, 12MHz) | 0.96" TFT `6:SCL` | 硬件 SPI1 Mode 0 + `DMA1_CH2` 异步刷屏（已真机点亮） |
| **TFT SPI 数据** | `PA7` (`SPI1_MOSI`, AF0) | 0.96" TFT `5:SDA` | 只写不读，无需 MISO |
| **TFT 命令/数据** | `PA6` (推挽输出) | 0.96" TFT `3:DC` | 命令/像素数据切换 |
| **TFT 硬件复位** | `PA1` (推挽输出) | 0.96" TFT `4:RES` | 低电平复位 |
| **TFT 片选/背光** | `PA12` (推挽输出) + `3.3V` | 0.96" TFT `2:CS` + `1:BLK` | `CS` 接 `PA12`；底板内置 `S8050` NPN 背光开关，`1:BLK` 与 `7:VCC` 同接 `3.3V` 常亮（`8:GND` 共地） |

## 3. 焊接与接线防坑 5 条红线

1. **严禁将 `GND` 接到 `INA219` 绿色端子 `Vin-`**：`Vin+` 与 `Vin-` 间仅隔 `0.1Ω` (`R100`) 采样电阻，二者同在高压正极侧；`GND` 只能接底排针 `Gnd` 与开发板 `GND`。*(若换回 `INA226` 模块，则需把 `VBS` 飞线并接到 `IN+`)*。
2. **`HUSB238` 必须与单片机共地，且 `V+` 绝不碰单片机**：`HUSB238` 黑色端子右口（`⊖ / GND`）务必引线接开发板 `GND`，左口（`⊕ / V+`）仅去 `INA219 Vin+`。
3. **双 MOS 模块按背面丝印接，别看卖家主图**：严格按背面文字 **`VIN+ / VIN-`（正面右侧上下口）接电源，`VOUT+ / VOUT-`（正面左侧上下口）接黄金电阻**。
4. **0.96" 彩屏与 `CH340` 供电安全**：京东方 `0.96"` TFT `VCC/BLK` **严禁接 5V**（只能 `3.3V`）；`CH340` 确认跳线在 `3.3V`，若插着 `ST-Link` 供电则 `CH340 VCC` 悬空不接。
5. **高功率负载防烫**：`10Ω` 黄金电阻在 `10W~12W` 以上裸放桌面会迅速升温烫手，务必架空远离杜邦线皮、纸张与鼠标垫，测完及时发 `P 0` 停机散热。
